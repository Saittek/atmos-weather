Solara Support

Thanks for using Solara Weather at solaraweather.com. For help with the app, account access, or App Store issues, email the support address on your App Store listing.

  • Location not working — check iOS Settings → Solara → Location
  • Alerts — US: National Weather Service; Canada: Environment Canada
  • Radar — requires network access to RainViewer / ECCC / NEXRAD tiles
  • Accounts — favorites sync when signed in; use Account → Change password while signed in
  • Forgot password — Sign in → Forgot password, or /reset-password (email link when RESEND_API_KEY is configured)
  • Language — Settings → Language (English / Français Canada)
  • Pro preview — Settings → Plan → Preview Pro (no payment yet; more favorites, ad-free)
  • Stargaze / Radar / Earth — on phone, use the modes row under Today or Settings → Explore
  • Widget empty — open Solara once with weather loaded, then add the Home Screen widget
